## Popis

```
INNTEO Field Tool je pracovní nástroj servisního technika HVAC a MaR. Vše, co na zakázce potřebujete, máte v telefonu – a funguje i bez připojení k internetu.

SERVISNÍ PROTOKOL
• Zákazník, zařízení, chladivo, měření (HP/LP, přehřátí, podchlazení, teploty)
• Rozpracovaný protokol se průběžně ukládá
• Archiv protokolů, export k tisku nebo do PDF, odeslání e-mailem
• Vlastní název firmy a kontakt na protokolu

F-GAS EVIDENCE
• Kontroly těsnosti, doplnění, odsátí, nové náplně
• Automatický přepočet na t CO₂e
• Export do CSV pro Excel
• Přehled intervalů kontrol těsnosti

REFERENCE PRO TECHNIKA
• P-T tabulky chladiv (R32, R410A, R134a, R290, R744 a další)
• Přehled chladiv – GWP, bezpečnostní třída, náhrady
• Chybové kódy klimatizací (Daikin, Mitsubishi Electric, Toshiba, LG, Samsung)
• Diagnostický průvodce poruchami
• Servisní checklisty

MaR
• Kalkulačky 4–20 mA, 0–10 V, průtok, výkon, Modbus
• Encyklopedie veličin a čidel (Ni1000, Pt100, NTC, tlak, průtok, CO₂…)
• CODESYS – příklady a tahák pro programování PLC
• MaR cheat sheet

SOUKROMÍ
Žádná registrace, žádná reklama, žádné sledování. Všechna data zůstávají pouze ve vašem zařízení. Zálohu si můžete kdykoli uložit do Souborů nebo poslat e-mailem.
```

## Poznámky pro Apple Review (App Review Information → Notes)

```
INNTEO Field Tool is a professional offline tool for HVAC and building-automation (MaR) service technicians in the Czech Republic.

No login is required. All features work offline; all data is stored only on the device.

Native features: the app bundles all content locally (works in airplane mode) and uses the iOS share sheet / Files integration to export service reports (HTML/PDF), F-Gas logs (CSV) and full data backups (JSON), and to restore backups from Files.

Suggested test: Protokol tab → fill a client name → tap "Tisk / PDF" (opens share sheet). Data tab → "Zálohovat".
```
